# Fixer Audio 3.0.0

- Interface reconstruída com React e componentes reais do Base UI.
- Topbar personalizada e fixa, com controles da janela, menus e região para arrastar.
- Somente o conteúdo central rola; o rodapé de ações também permanece fixo.
- Scrollbars personalizadas na tela, fila, resultados e dropdowns.
- Superfícies cinzas mais escuras, ícones Lucide e tipografia por função.
- Cursor pointer nas ações clicáveis, com estados de foco, hover e desabilitado.
- Mantém os quatro modos de mídia, fila em lote, cancelamento, instalação do FFmpeg e atualizações via GitHub.

Instale `FixerAudioAMD-Setup.exe` sobre a versão anterior. O instalador substitui o runtime antigo. Requer Microsoft Edge WebView2 Runtime (normalmente presente no Windows 10/11).
