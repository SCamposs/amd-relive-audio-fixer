# Product

## Register

product

## Users

Windows users who record clips with AMD ReLive and want a small utility for repairing audio playback or removing embedded metadata from media files.

## Product Purpose

Make two recurring media cleanup tasks fast and explicit: convert problematic 7.1 ReLive audio to stereo, and remove embedded metadata without re-encoding the media streams.

## Brand Personality

Industrial, focused, direct. The interface borrows the compact HUD character of ARC Raiders while remaining a practical desktop utility.

## Anti-references

Default Tkinter styling, generic corporate utilities, decorative gaming UI that obscures the task, and workflows that hide destructive behavior.

## Design Principles

- Keep audio repair and metadata cleanup clearly separated.
- State when files will be overwritten before an operation begins.
- Preserve media quality whenever stream copying is possible.
- Show dependency, progress, success, and failure states in plain language.
- Surface available updates without interrupting the current task.
- Keep the visual system compact and consistent across both workflows.

## Accessibility & Inclusion

Maintain readable contrast, pair status colors with text, keep controls and dialogs predictable, and avoid motion that is not tied to operation progress.
