# Fixer Audio desktop

Qt Widgets, dark industrial utility. Native Windows title bar retains maximize, snap, system menu and taskbar behavior. Barlow carries the interface; monospace is reserved for operation logs. The multicolor mark identifies the app, cyan divides the header and amber identifies the primary action, focus and updates.

Use resizable layouts, 32 px content margins, 16 px spacing, 6 px control corners and explicit hover, keyboard focus, disabled and running states. Dropdowns are QComboBox popups, not simulated menus. File lists use row selection. Errors stay visible in the results pane. Destructive cleanup requires explicit confirmation. Animation is limited to processing feedback.
