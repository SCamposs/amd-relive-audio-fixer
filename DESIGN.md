# Fixer Audio desktop

React + Base UI inside a Windows WebView2 shell. Custom fixed title bar with drag region, menus and minimize/maximize/close controls. Body and controls use bundled Barlow; paths, HUD and logs use JetBrains Mono; headings prefer locally installed Handel Gothic/Bahnschrift and fall back to bundled Barlow Semi Condensed. The logo prefers locally installed Avant Garde/Century Gothic, with Barlow as fallback. Commercial fonts are not redistributed.

Near-black surfaces, amber action/focus, clear text and restrained semantic green. Base UI provides Select, Menu, Button, Checkbox and Dialog primitives with custom styling and Lucide icons. Interactive actions use pointer cursors. Custom thin scrollbars apply to the central content, queue, results and popups; the title bar and footer stay outside the scroller. Reduced-motion support disables progress movement. Destructive cleanup requires explicit confirmation.
